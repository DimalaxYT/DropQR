05 / MODE D'EMPLOI

Comment utiliser DropQR.

Aucune création de compte n'est requise. Voici comment envoyer et recevoir vos fichiers en toute sécurité.

Envoyer un fichier

Pour transférer un document :

  1. Rendez-vous sur la page Envoyer.
  2. Sélectionnez un ou plusieurs fichiers depuis votre appareil (ordinateur, tablette ou téléphone).
  3. Configurez si besoin la durée d'expiration (de 15 minutes à 24 heures).
  4. Choisissez si le fichier doit être supprimé immédiatement après le premier téléchargement.
  5. Cliquez sur Envoyer. Une fois terminé, vous obtiendrez un QR Code et un code court.

Recevoir un fichier

Le destinataire a deux options très simples :

  1. Scanner le QR Code : il suffit d'utiliser l'appareil photo du téléphone pour être redirigé vers la page de téléchargement direct.
  2. Utiliser le Code court : le destinataire se rend sur la page Recevoir et saisit le code (ex : Q7R4M2K, 7 caractères) qui lui a été communiqué à l'oral ou par message.

Y a-t-il des limites de taille ?

Le système a été conçu pour envoyer rapidement de gros volumes en les découpant (upload parallèle). La limite maximale dépend des paramètres actuels de l'hébergeur, mais peut aller jusqu'à plusieurs Gigaoctets par fichier.

Assurez-vous simplement que vous avez une connexion stable, DropQR s'occupe de gérer le transfert en arrière-plan pour éviter toute coupure réseau.

Où vont mes fichiers ? (Sécurité)

DropQR est un outil de transfert de type "sas d'échange" (et non un stockage cloud type Google Drive). Cela signifie que vos fichiers ne restent jamais sur nos serveurs de façon permanente.

Le fichier est définitivement supprimé et irrécupérable dans 3 cas :

  • Lorsque le temps défini au moment de l'envoi expire (ex: 15 minutes).
  • Immédiatement après le téléchargement du destinataire (si vous avez coché l'option).
  • Manuellement par vous-même depuis l'interface juste après l'envoi.

Aperçu des vidéos

Si vous envoyez un fichier vidéo (MP4, WebM, etc.), le destinataire n'aura pas obligatoirement besoin de le télécharger pour le regarder. DropQR inclut un lecteur vidéo sécurisé directement sur la page de réception.
